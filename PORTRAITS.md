# BBS Sabacc Portrait System

The BBS Sabacc game features a XBin-based portrait system for AI players.

## Portrait Specifications

- **Dimensions**: Exactly 9 columns × 6 rows
- **Format**: XBin (.xb) files only - full color ANSI art format
- **Default**: Included `ansi/portraits.xb` with 4 character portraits (add more!)
- **Randomization**: Different portraits selected each game session

## Binary File Format

The portrait file (`portraits.bin`) uses a simple binary format:

```
Header: 4 bytes (uint32, little-endian) - Number of portraits
Data:   For each portrait, 108 bytes total:
        - 54 bytes of character data (9×6 characters)
        - 54 bytes of attribute data (9×6 color/formatting)
```

### File Structure Example:
```
Offset  Size  Description
0x00    4     Number of portraits (e.g., 0x04000000 = 4 portraits)
0x04    54    Portrait 1 character data (9×6 chars)
0x3A    54    Portrait 1 attribute data (9×6 colors)
0x70    54    Portrait 2 character data (9×6 chars)  
0xA6    54    Portrait 2 attribute data (9×6 colors)
...     108   Additional portraits (108 bytes each)...
```

## Build-Time Portrait Generation

Portraits are generated at build-time using the portrait tool, following the same pattern as cards:

```bash
# Build the portrait tool
go build -o portraits ./cmd/portraits

# Extract portraits from XBin file to binary format
./portraits extract portraits.bin ansi/portraits.xb

# Show information about a portrait file
./portraits info portraits.bin

# Game then loads the pre-built portraits.bin at runtime
go build .
./bbs-sabacc
```

### Supported Input Formats

#### XBin Format (.xb)
XBin (eXtended Binary) is the exclusive format supported for ANSI artwork input:

**Why XBin:**
- Preserves exact character data and color attributes
- Maintains precise dimensions and formatting
- Industry standard for BBS ANSI artwork
- Better handling of complex CP437 characters
- No ambiguity from ANSI escape sequences

## Runtime Portrait Loading

The game loads portraits at runtime with graceful fallback:
1. **Load `portraits.bin`** - Pre-built portrait file (generated by portrait tool)
2. **Fallback to placeholders** - Simple "[AI 1]" text if no portraits available

### Portrait Selection:
- Randomly selects different portraits for each AI player
- Ensures each AI player gets a unique portrait (when possible)
- Selection varies each game session

### XBin Source File:
The included `ansi/portraits.xb` contains 4 character portraits designed for the Star Wars cantina theme. Use the portrait tool to extract this to `portraits.bin`.
